# 汇率换算在净值汇总中的真实生效路径分析

## 1. 概述

本报告深入分析汇率换算在净值汇总链路中的**三层架构**，重点澄清：
- **导入阶段**：不进行汇率换算
- **同步计算阶段**：将 Entry/Holding 换算为账户货币（核心入口）
- **展示汇总阶段**：将账户余额换算为家族货币

```ruby
def import!
  transaction do
    mappings.each(&:create_mappable!)

  end
```

## 4. 阶段二：同步计算阶段（核心换算点）

### 4.1 完整调用链路

```
Account::Syncer.perform_sync
    ↓
Account::Syncer.import_market_data
    ↓
Account::MarketDataImporter.import_all
    ↓
Account::MarketDataImporter.import_exchange_rates  # 预获取汇率
    ↓
Account::Syncer.materialize_balances
    ↓

    ↓

    ↓

    ↓

    ↓

    ↓

    ↓
Balance::Materializer.persist_balances  # 持久化（账户货币）
```

### 4.2 核心换算入口：Balance::SyncCache

**代码位置**：[balance/sync_cache.rb](file:///d:/fz/0508-1/solo-dogfeeding/code/122-maybe/app/models/balance/sync_cache.rb)

```ruby
class Balance::SyncCache
  def initialize(account)
    @account = account
  end

  # 核心换算入口1：Entry金额换算
  def converted_entries
    @converted_entries ||= account.entries.order(:date).to_a.map do |e|
      converted_entry = e.dup
      converted_entry.amount = converted_entry.amount_money.exchange_to(
        account.currency,       # 目标货币：账户货币
        date: e.date,           # 使用交易日期的汇率
        fallback_rate: 1        # 缺失汇率时默认1:1
      ).amount
      converted_entry.currency = account.currency
      converted_entry
    end
  end

  # 核心换算入口2：Holding金额换算
  def converted_holdings
    @converted_holdings ||= account.holdings.map do |h|
      converted_holding = h.dup
      converted_holding.amount = converted_holding.amount_money.exchange_to(
        account.currency,       # 目标货币：账户货币
        date: h.date,           # 使用持仓日期的汇率
        fallback_rate: 1        # 缺失汇率时默认1:1
      ).amount
      converted_holding.currency = account.currency
      converted_holding
    end
  end
end
```

### 4.3 汇率获取机制

**代码位置**：[lib/money.rb](file:///d:/fz/0508-1/solo-dogfeeding/code/122-maybe/lib/money.rb#L42-L55)

```ruby
def exchange_to(other_currency, date: Date.current, fallback_rate: nil)
  iso_code = currency.iso_code
  other_iso_code = Money::Currency.new(other_currency).iso_code

  if iso_code == other_iso_code
    self
  else
    exchange_rate = store.find_or_fetch_rate(
      from: iso_code,
      to: other_iso_code,
      date: date
    )&.rate || fallback_rate

    raise ConversionError unless exchange_rate
    Money.new(amount * exchange_rate, other_iso_code)
  end
end
```

### 4.4 预获取机制

**代码位置**：[account/market_data_importer.rb](file:///d:/fz/0508-1/solo-dogfeeding/code/122-maybe/app/models/account/market_data_importer.rb#L13-L43)

```ruby
def import_exchange_rates
  return unless needs_exchange_rates?

  # 1. 条目级货币对（Entry.currency ≠ Account.currency）
  account.entries
         .where.not(currency: account.currency)
         .group(:currency)
         .minimum(:date)
         .each do |source_currency, date|
    ExchangeRate.import_provider_rates(
      from: source_currency,
      to: account.currency,
      start_date: date,
      end_date: Date.current
    )
  end

  # 2. 账户级货币对（Account.currency ≠ Family.currency）
  if foreign_account?
    ExchangeRate.import_provider_rates(
      from: account.currency,
      to: account.family.currency,
      start_date: account.start_date,
      end_date: Date.current
    )
  end
end
```

```ruby
def persist_balances
  current_time = Time.now
  account.balances.upsert_all(
    @balances.map { |b| b.attributes
           .slice("date", "balance", "cash_balance", "currency",
                  "start_cash_balance", "start_non_cash_balance",
                  "cash_inflows", "cash_outflows",
                  "non_cash_inflows", "non_cash_outflows",
                  "net_market_flows",
                  "cash_adjustments", "non_cash_adjustments",
                  "flows_factor")
           .merge("updated_at" => current_time) },
    unique_by: %i[account_id date currency]
  )
end
```

### 5.2 当前净值汇总

**代码位置**：[balance_sheet/account_totals.rb](file:///d:/fz/0508-1/solo-dogfeeding/code/122-maybe/app/models/balance_sheet/account_totals.rb#L48-60)

```ruby
def query
  @query ||= Rails.cache.fetch(cache_key) do
    visible_accounts
      .joins(ActiveRecord::Base.sanitize_sql_array([
        "LEFT JOIN exchange_rates ON exchange_rates.date = ? 
         AND accounts.currency = exchange_rates.from_currency 
         AND exchange_rates.to_currency = ?",
        Date.current,                    # 使用当天汇率
        family.currency                  # 目标货币：家族货币
      ]))
      .select(
        "accounts.*",
        "SUM(accounts.balance * COALESCE(exchange_rates.rate, 1)) as converted_balance"
      )
      .group(:classification, :accountable_type, :id)
      .to_a
  end
end
```

### 5.3 历史时间序列

**代码位置**：[balance/chart_series_builder.rb](file:///d:/fz/0508-1/solo-dogfeeding/code/122-maybe/app/models/balance/chart_series_builder.rb#L94-150)

```ruby
def query
  <<~SQL
    WITH dates AS (
      SELECT generate_series(DATE :start_date, DATE :end_date, :interval::interval)::date AS date
    )
    SELECT
      d.date,
      COALESCE(SUM(last_bal.end_balance * last_bal.flows_factor * COALESCE(er.rate, 1) * :sign_multiplier::integer), 0) AS end_balance,
      -- ... 其他字段
    FROM dates d
    CROSS JOIN accounts
    LEFT JOIN LATERAL (
      SELECT b.end_balance, b.end_cash_balance, ..., b.flows_factor
      FROM balances b
      WHERE b.account_id = accounts.id AND b.date <= d.date
      ORDER BY b.date DESC LIMIT 1
    ) last_bal ON TRUE
    LEFT JOIN LATERAL (
      SELECT er.rate
      FROM exchange_rates er
      WHERE er.from_currency = accounts.currency
        AND er.to_currency = :target_currency
        AND er.date <= d.date           -- 使用<=日期的最新汇率
      ORDER BY er.date DESC LIMIT 1
    ) er ON TRUE
    WHERE accounts.id = ANY(array[:account_ids]::uuid[])
    GROUP BY d.date
    ORDER BY d.date
  SQL
end
```

### 5.4 结论

| 特性 | 当前净值汇总 | 历史时间序列 |
|------|-------------|-------------|
| 汇率介入 | **YES** | **YES** |
| 换算方向 | 账户货币 → 家族货币 | 账户货币 → 家族货币 |
| 时间基准 | Date.current | <= 历史日期的最新汇率（LOCF） |
| 持久化 | 不持久化，仅查询时计算 | 不持久化，仅查询时计算 |

## 7. 关键设计要点总结

### 7.1 两层换算架构

| 层级 | 位置 | 换算方向 | 时间基准 | 持久化 |
|------|------|---------|---------|---------|
| 第一层 | Balance::SyncCache | Entry/Holding→账户货币 | 交易/持仓日期 | 是（Balance记录） |
| 第二层 | AccountTotals/ChartSeriesBuilder | 账户货币→家族货币 | 当前/历史日期 | 否（仅查询时） |

### 7.2 汇率获取策略

1. **预获取**：同步前通过 `Account::MarketDataImporter` 批量获取所需汇率
2. **按需获取**：`Money#exchange_to` 通过 `ExchangeRate.find_or_fetch_rate` 实时获取
3. **LOCF填充**：`ExchangeRate::Importer` 使用最后观察值结转填充缺失日期

### 7.3 容错机制

- **缺失汇率**：`COALESCE(exchange_rates.rate, 1)` 默认1:1
- **provider失败**：`ExchangeRate.find_or_fetch_rate` 返回nil，不中断流程
- **缓存失效**：通过 `family.build_cache_key` 在数据更新时自动失效

### 7.4 常见混淆点澄清

| 误解 | 真相 |
|------|------|
| 汇率换算只在展示阶段发生 | ❌ 同步计算阶段也有核心换算（Entry→账户货币） |
| Account.balance 存储换算后金额 | ❌ 存储账户货币，不是家族货币 |
| 导入时进行汇率换算 | ❌ 导入时数据原样写入 |
| Balance记录存储家族货币 | ❌ 存储账户货币，展示时再换算 |
