### 2.2 入口一：BalanceSheet 净值汇总

**触发链路**：
```
User visits Dashboard
    ↓
BalanceSheet.new(family)
    ↓
BalanceSheet#assets / #liabilities
    ↓
BalanceSheet::ClassificationGroup.new
    ↓
BalanceSheet::AccountTotals.new
    ↓
AccountTotals#account_rows → AccountTotals#query
```

**汇率换算核心代码**（[account_totals.rb:L48-60](file:///d:/fz/0508-1/solo-dogfeeding/code/122-maybe/app/models/balance_sheet/account_totals.rb#L48-L60)）：

```ruby
def query
  @query ||= Rails.cache.fetch(cache_key) do
    visible_accounts
      .joins(ActiveRecord::Base.sanitize_sql_array([
        "LEFT JOIN exchange_rates ON exchange_rates.date = ? AND accounts.currency = exchange_rates.from_currency AND exchange_rates.to_currency = ?",
        Date.current,                    # 使用当天汇率
        family.currency                  # 换算目标：家族货币
      ]))
      .select(
        "accounts.*",
        "SUM(accounts.balance * COALESCE(exchange_rates.rate, 1)) as converted_balance"
      )
      .group(:classification, :accountable_type, :id)
      .to_a
  end
end
```

**关键特征**：
- **时间点**：使用 `Date.current` 的汇率
- **换算方向**：`accounts.currency` → `family.currency`
- **容错机制**：`COALESCE(rate, 1)` 无汇率时默认 1:1
- **缓存策略**：通过 `family.build_cache_key` 实现数据更新时自动失效

### 2.3 入口二：历史图表时间序列

**触发链路**：
```
User views Balance Chart
    ↓

    ↓
BalanceSheet::NetWorthSeriesBuilder#net_worth_series
    ↓
Balance::ChartSeriesBuilder.new
    ↓
ChartSeriesBuilder#balance_series → ChartSeriesBuilder#query_data → ChartSeriesBuilder#query
```

**汇率换算核心代码**（[chart_series_builder.rb:L94-150](file:///d:/fz/0508-1/solo-dogfeeding/code/122-maybe/app/models/balance/chart_series_builder.rb#L94-L150)）：

```ruby
def query
  <<~SQL
    WITH dates AS (
      SELECT generate_series(DATE :start_date, DATE :end_date, :interval::interval)::date AS date
    )
    SELECT
      d.date,
      COALESCE(SUM(last_bal.end_balance * last_bal.flows_factor * COALESCE(er.rate, 1) * :sign_multiplier::integer), 0) AS end_balance,
      -- ... 其他字段
    FROM dates d
    CROSS JOIN accounts
    LEFT JOIN LATERAL (
      SELECT b.end_balance, b.end_cash_balance, ..., b.flows_factor
      FROM balances b
      WHERE b.account_id = accounts.id AND b.date <= d.date
      ORDER BY b.date DESC LIMIT 1
    ) last_bal ON TRUE
    LEFT JOIN LATERAL (
      SELECT er.rate
      FROM exchange_rates er
      WHERE er.from_currency = accounts.currency
        AND er.to_currency = :target_currency
        AND er.date <= d.date           -- 使用 <= 当前日期的最新汇率
      ORDER BY er.date DESC LIMIT 1
    ) er ON TRUE
    WHERE accounts.id = ANY(array[:account_ids]::uuid[])
    GROUP BY d.date
    ORDER BY d.date
  SQL
end
```

**关键特征**：
- **时间点**：使用 `<= d.date` 的最新汇率（LOCF 策略）
- **动态换算**：每天使用当天有效的汇率
- **资产/负债处理**：通过 `flows_factor` 和 `sign_multiplier` 处理符号

### 4.2 各阶段详细分析

#### 4.2.1 阶段一：交易写入

**映射配置来源**（[transaction_import.rb](file:///d:/fz/0508-1/solo-dogfeeding/code/122-maybe/app/models/transaction_import.rb)）：

```ruby
def import!
  transaction do
    mappings.each(&:create_mappable!)  # 创建新的分类/标签/账户

    transactions = rows.map do |row|
      # 1. 账户映射
      mapped_account = if account
        account  # 导入时指定了账户
      else
        mappings.accounts.mappable_for(row.account)  # 通过映射查找
      end

      # 2. 分类映射
      category = mappings.categories.mappable_for(row.category)

      # 3. 标签映射（支持多标签）
      tags = row.tags_list.map { |tag| mappings.tags.mappable_for(tag) }.compact

      Transaction.new(
        category: category,
        tags: tags,
        entry: Entry.new(
          account: mapped_account,
          date: row.date_iso,
          amount: row.signed_amount,
          name: row.name,
          currency: row.currency,  # ← 直接使用CSV货币，不换算
          notes: row.notes,
          import: self
        )
      )
    end

    Transaction.import!(transactions, recursive: true)
  end
end
```

**生效边界**：
- ✅ 映射结果写入 `Entry.account_id`、`Transaction.category_id`、`Transaction.tags`
- ❌ 不涉及汇率换算，`Entry.currency` 直接来自 CSV
- ❌ 不影响账户余额计算

```ruby
def import!
  transaction do
    rows.each do |row|
      # 账户类型映射
      mapping = mappings.account_types.find_by(key: row.entity_type)

  end
end
```

**生效边界**：
- ✅ 映射结果写入 `Account.accountable_type`

- ❌ 不涉及汇率换算

## 5. 常见混淆路径澄清

### 5.1 澄清一：导入时是否进行汇率换算？

**结论**：**否**

```ruby
# TransactionImport.import! - 直接写入，不换算
Entry.new(
  ...
  currency: row.currency,  # 原样写入CSV货币
  ...
)

# AccountImport.import! - 直接写入，不换算
Account.new(
  ...
  balance: row.amount.to_d,  # 原样写入CSV金额
  currency: row.currency,    # 原样写入CSV货币
  ...
)
```

**原因**：
1. **数据完整性**：保持原始交易记录的货币信息
2. **时间一致性**：汇率随时间波动，导入时换算会丢失历史准确性
3. **灵活展示**：支持按原始货币或家族货币展示

### 5.2 澄清二：余额表展示时使用什么汇率？

**结论**：**使用当前日期的汇率**（对于当前余额）或 **使用历史日期的汇率**（对于时间序列）

```ruby
# 当前余额汇总 - 使用 Date.current 汇率
"LEFT JOIN exchange_rates ON exchange_rates.date = ?", Date.current

# 历史时间序列 - 使用 <= 历史日期的最新汇率
"LEFT JOIN LATERAL (
  SELECT er.rate
  FROM exchange_rates er
  WHERE er.date <= d.date
  ORDER BY er.date DESC LIMIT 1
) er ON TRUE"
```

### 5.3 澄清三：映射配置何时生效？

**结论**：**映射在导入阶段立即生效**，余额汇总阶段不再使用映射

```
导入阶段：映射配置 → 写入数据库 (Entry/Transaction/Account)
    ↓
余额汇总阶段：直接读取数据库 → SQL JOIN 汇率 → 换算展示
```

### 5.4 澄清四：Account.balance 字段存储的是什么？

**结论**：**存储账户原始货币的余额**，不是换算后的金额

```ruby
# Account model
monetize :balance, :cash_balance  # 使用账户自身的currency

# 换算仅在查询时发生
"accounts.balance * COALESCE(exchange_rates.rate, 1) as converted_balance"
```

## 6. 汇率获取与缓存策略

### 6.1 汇率预获取机制

**触发时机**：账户同步时

```ruby
# Account::MarketDataImporter.import_exchange_rates
def import_exchange_rates
  return unless needs_exchange_rates?

  # 1. 条目级货币对（Entry.currency ≠ Account.currency）
  account.entries
         .where.not(currency: account.currency)
         .group(:currency)
         .minimum(:date)
         .each do |source_currency, date|
    ExchangeRate.import_provider_rates(
      from: source_currency,
      to: account.currency,
      start_date: date,
      end_date: Date.current
    )
  end

  # 2. 账户级货币对（Account.currency ≠ Family.currency）
  if foreign_account?
    ExchangeRate.import_provider_rates(
      from: account.currency,
      to: account.family.currency,
      start_date: account.start_date,
      end_date: Date.current
    )
  end
end
```

### 6.2 汇率缓存机制

| 层级 | 缓存位置 | 失效条件 |
|------|---------|---------|
| **数据层** | `exchange_rates` 表 | 手动刷新或 provider 更新 |
| **查询层** | Rails.cache (AccountTotals) | `family.build_cache_key` 数据更新时失效 |
| **展示层** | Rails.cache (NetWorthSeriesBuilder) | 周期参数变化或数据更新时失效 |

## 7. 总结

### 7.1 核心要点

1. **汇率换算只发生在展示阶段**：导入和同步阶段不进行换算
2. **真实入口有两个**：
    - `BalanceSheet::AccountTotals.query` - 当前净值汇总
    - `Balance::ChartSeriesBuilder.query` - 历史时间序列
3. **映射配置在导入阶段一次性生效**：写入数据库后不再使用映射
4. **账户余额始终存储原始货币**：换算仅在查询时通过 SQL JOIN 实现
5. **容错机制完善**：缺失汇率时默认 rate=1，不中断业务

### 7.2 关键流程图

```
数据流向：
CSV → Import::Row → Entry/Transaction/Account (原始货币)
                       ↓
              ExchangeRate (预获取并缓存)
                       ↓
              BalanceSheet (查询时JOIN汇率)
                       ↓
              展示给用户 (家族货币)
```
